# My Life 🌟

A simple personal website created to introduce **Abhinav Kumar Anand** and share a few things about his life, family, friends, and favourites.

## 📌 About the Website

The website is a personal homepage titled **"My Life"**. The homepage contains an introduction and navigation links to other sections of the site.

The homepage includes:
- **Home** – Introduction and basic information
- **Family** – Family information
- **Friends** – Friends section
- **Favourites** – Favourite things

## 🧑 About Me

Hello! I am **Abhinav Kumar Anand**. I live in **Hyderabad** and was born in **Uttar Pradesh on 20 March 2012**.

This website was made after my final exams as a personal project and as a way to show my friends what I can create.

## 🗂️ Project Structure

```text
My-Life/
├── index.html
├── styles.css
├── family.html
├── friends.html
└── favourites.html
```

> The HTML homepage links to `styles.css`, `family.html`, `friends.html`, and `favourites.html`.

## ✨ Features

- Personal introduction page
- Navigation between different sections
- Custom page title
- Emoji-based SVG favicon 🧑
- Separate pages for family, friends, and favourites
- Simple HTML structure

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **SVG** for the favicon

## 🚀 How to Run

1. Download or clone this project.
2. Keep all HTML and CSS files in the same folder.
3. Open `index.html` in a web browser.
4. Use the navigation links to explore the website.

## 📄 Main Page

The main page is `index.html`. It contains the page title, navigation menu, introduction, closing message, and footer.
